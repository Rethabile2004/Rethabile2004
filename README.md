## Projects

**[TaskFlow API](https://github.com/Rethabile2004/taskflow-api)**
REST API with JWT authentication, user-scoped data, Repository and Service layer separation, global exception handling, structured logging with Serilog, and full CRUD with filtering, sorting, and pagination.

**[EduTrack](https://github.com/Rethabile2004/aspnetcore-db)**
Role-based student enrollment system built with ASP.NET Core MVC and Identity. Two-tier access control, photo uploads, Repository Pattern, and paginated/sortable listings via EF Core Code First.

**[Next Commerce](https://github.com/Rethabile2004/next-commerce)**
Full-stack e-commerce platform with authentication, product listings, cart, and order flow. End-to-end TypeScript, deployed on Vercel.

**[Travel Guide SA](https://github.com/Rethabile2004/travel-guide)**
Data-driven travel platform with authentication and structured relational database design.
